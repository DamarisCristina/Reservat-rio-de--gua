# Controle de Níveis de Água

## 📖 Sobre o Projeto

Este projeto simula um sistema simples de monitoramento de um reservatório de água utilizando Python no terminal.

A proposta é informar a quantidade de litros presente no reservatório e, com base nesse valor, classificar automaticamente o nível da água, exibindo mensagens de alerta coloridas para facilitar a visualização.

---

## 🚀 Funcionalidades

* Solicita a quantidade de litros do reservatório
* Classifica o nível da água em 5 categorias
* Exibe mensagens coloridas conforme a situação
* Utiliza a biblioteca `colorama`
* Código organizado com funções e listas

---

## 📊 Classificação dos Níveis

| Nível   | Situação              | Cor      |
| ------- | --------------------- | -------- |
| Nível 1 | Muito baixo (crítico) | Vermelho |
| Nível 2 | Baixo                 | Amarelo  |
| Nível 3 | Médio                 | Verde    |
| Nível 4 | Alto                  | Ciano    |
| Nível 5 | Muito alto (alerta)   | Azul     |
